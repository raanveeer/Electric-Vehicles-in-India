# EV Knowledge Hub — PS 04 practice website

A responsive, single-page HTML practice site for the “Get Cited” GEO competition.

## Files
- `index.html` — full website, CSS, metadata, and Article JSON-LD.
- `robots.txt` — basic crawler instructions.
- `sitemap.xml` — URL discovery file.
- `README.md` — setup instructions.

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload all three website files (`index.html`, `robots.txt`, `sitemap.xml`) to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for deployment and open the URL GitHub Pages provides.

## Required edits after you know the final URL
In `index.html`, replace both occurrences of:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
with your exact public site URL.

In `robots.txt`, replace the sitemap URL with:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/sitemap.xml`

In `sitemap.xml`, replace the example URL with your exact public site URL.

## Before competition submission
- Verify every current policy claim against official sources.
- Replace this practice topic with the assigned topic if required.
- Update the visible review date and JSON-LD dates to the real dates.
- Check all links and ensure no placeholder remains.
- Keep visible page content consistent with structured data.
- The page does not guarantee AI citations; organisers' independent test determines the result.
